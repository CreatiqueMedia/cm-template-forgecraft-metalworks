# ForgeCraft Metalworks

> Custom metal fabrication website template for RFQs, installs, and gallery proof.

## Live Demo

See it in action: [https://creatiquemedia.com/templates/forgecraft-metalworks/demo](https://creatiquemedia.com/templates/forgecraft-metalworks/demo)

## Who It Is For

Metal fabricators, decorative ironworks shops, custom gate builders, and specialty fabrication studios.

A metalworks template for custom fabrication shops with project scopes, material options, quote filters, and gallery proof.

## What's Included

**Key sections and features:**

- Project-scope intake by material, finish, and timeline
- Residential and commercial job-path segmentation
- Fabrication gallery with process credibility sections
- Maintenance and installation add-on conversion paths

**Additional features:**

- Scope qualifier form for dimensions, metal type, and delivery timeline
- Separate residential and commercial conversion blocks
- Material and finish guide for steel, stainless, aluminum, and custom finishes
- Fabrication proof: process photos, weld quality highlights, install outcomes
- Install and maintenance plan offer blocks
- Quote-ready RFQ flow with file upload and callback routing

**Demo page blocks:** Material Selector, Drawing Upload RFQ, Install Planning Board.

## Design & Tech Highlights

Built with Next.js, React, TypeScript, and Tailwind CSS, with Stripe and PWA support listed in the template stack.
